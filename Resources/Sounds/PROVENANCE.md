# Talkie earcons (K2)

Six short feedback cues for the moments Talkie marks audibly. `Feedback.swift`
resolves each **bundled-first**: it plays `Resources/Sounds/<name>.caf` if present,
and otherwise falls back to the same-purpose macOS system sound — so a missing or
removed asset degrades gracefully to today's behavior, never to a crash or silence.

| Cue | File | Fires on | System fallback |
|-----|------|----------|-----------------|
| start | `chirp-start.caf` | dictation begins (rising) | Tink |
| stop | `chirp-stop.caf` | dictation ends (falling) | Pop |
| done | `chirp-done.caf` | text inserted (two-note) + subtle haptic | Morse |
| lock | `chirp-lock.caf` | hands-free latch (tap · latch) + firmer haptic | Bottle |
| clipboard | `chirp-clipboard.caf` | couldn't paste, left on clipboard (double) | Submarine |
| learn | `chirp-learn.caf` | a word was learned (bright rising) | Glass |

## Status: PLACEHOLDER — pending sound design

These `.caf` files are **gentle synthesized sine chimes**, generated by the
checked-in script for the interim so the whole feedback path (bundled resolution,
fallback, haptics, bundle copy) ships and works end to end. They are deliberately
quiet and short so they never jar.

The **intended** family is *macaw-derived* — short cues recorded/processed from real
macaw calls, coherent as a set — which is a human sound-design pass, not something to
synthesize. When those land, drop the replacements in here under the same filenames
and they take over automatically (no code change).

## Regenerating the placeholders

```
python3 scripts/gen_earcons.py
```

Requires only the Python stdlib and `afconvert` (bundled with macOS). Edit the
`EARCONS` table in that script to retune pitch/length/gain.
